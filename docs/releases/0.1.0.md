## 포함 기능

- Codex 모델 목록과 지원 effort 동적 조회
- 질문별 모델/effort 선택, 대화 맥락을 유지하는 후속 질문
- 비동기 공개 응답 조회, 특정 발언 중단, 저장 대화 재개
- 읽기 전용 프로젝트 탐색, CLI 로그인/provider 설정 재사용
- Claude Code, Antigravity CLI, Kiro CLI 등록 안내

## 게시 검증

GitHub에서 타입 검사, 48개 테스트, 빌드, tarball 설치 검증 후 동일 파일을 게시했다.
익명으로 버전별 메타데이터와 공개 tarball을 조회했으며, tarball의 SHA-512가
GitHub artifact와 일치함을 확인했다. 공개 npm tarball URL을 새 임시 폴더에
설치해 버전 `0.1.0`, 5개 MCP 도구와 모델 목록 호출을 검증했다.
이후 빈 npm 캐시와 인증 설정 없이 패키지 이름
`@mirolab/codex-discussion-mcp@0.1.0`으로 새로 설치하고 실행 버전도 확인했다.

```bash
npm install -g @mirolab/codex-discussion-mcp@0.1.0
```
