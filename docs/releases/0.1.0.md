## Included Features

- Dynamic discovery of Codex models and supported effort levels
- Model/effort selection for each question and follow-up questions that retain discussion context
- Asynchronous public response retrieval, cancellation of a specific turn, and resumption of persisted discussions
- Read-only project exploration and reuse of CLI login/provider configuration
- Registration instructions for Claude Code, Antigravity CLI, and Kiro CLI
