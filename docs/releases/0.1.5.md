## Changes

- Add `discussion_forget` to release inactive local discussion output and cursors
  without deleting saved Codex history. Reject active, pending, loading, or
  uncertain work, including unknown submissions and observed external activity.
- Preserve previously fetched history pages after disconnect, including
  concurrent read/disconnect races.
- Inherit reply model and effort from current persisted thread defaults and
  clear stale effort when a changed saved model has no effort value.
- Ship the authenticated remote app-server setup script and guide. The MCP
  connection continues to use local stdio.
- Clarify model selection and disclosure, add Skills CLI installation guidance,
  and ship `CHANGELOG.md`. Contributor and publishing instructions now require
  a dated changelog entry and matching GitHub Release notes for every npm version.
