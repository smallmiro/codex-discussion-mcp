## Changes

This release contains no runtime behavior changes from `0.1.0`.

- Translated the README and the shipped publishing guide to English
- Translated the design, verification and release records to English
- Added `AGENTS.md` as a contributor guide
- Switched the live smoke test to English prompts
- Made the CLI version test compare against `package.json` instead of a fixed version

## Publication Path

Publishing the GitHub Release started the OIDC `publish.yml` workflow. It passed
the checks and tarball verification, but npm rejected the upload with `E404`
because no Trusted Publisher is configured for the package yet
([failed run](https://github.com/smallmiro/codex-discussion-mcp/actions/runs/40189021816)).
The same commit was then published through `bootstrap-publish.yml` with version
input `0.1.1`. An earlier `v0.1.1` tag on `376f0c9` failed the version test before
publishing anything and was replaced by the tag on `38af23d`.

## Publication Verification

and tarball installation verification on GitHub. The registry's version metadata
reports the SHA-512 below, and the anonymously downloaded public tarball and the
GitHub artifact `bootstrap-npm-package` both hash to the same value. The `latest`
