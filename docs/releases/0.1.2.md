# 0.1.2

Release status: Prepared on 2026-10-31. Publication and fresh-install verification
are pending; this record will be updated with the actual artifact identity.

- npm: `@mirolab/codex-discussion-mcp@0.1.2`
- Intended distribution tag: `latest`
- Intended Git tag: `v0.1.2`

## Changes

This release adds user guidance and packaged documentation without changing the
MCP runtime API.

- Include the portable `codex-discussion` skill, its setup and tool references,
  and a complete user manual in the npm package ([PR #4](https://github.com/smallmiro/codex-discussion-mcp/pull/4)).
- Explain current-project defaults, explicit and relative project paths,
  evidence-based source/test reviews, result polling, and same-project follow-ups
  ([PR #6](https://github.com/smallmiro/codex-discussion-mcp/pull/6)).
- Document skill installation, invocation, updates, troubleshooting, and
  host-specific integration limits. Installing the MCP package alone does not
  install a skill into a host's discovery directory.
- Record compatibility verification against Codex CLI `0.166.0`
  ([PR #2](https://github.com/smallmiro/codex-discussion-mcp/pull/2)).
- Verify all shipped guide files during isolated tarball installation and make
  the test fixture's saved snapshots resilient to interrupted writes.

## Install

After publication:

```bash
npm install -g @mirolab/codex-discussion-mcp@0.1.2
```

Follow the [skill manual](../skills.md) to copy the complete skill directory into
your host. Existing installed skill copies must be updated separately.
