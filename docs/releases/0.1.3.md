# 0.1.3

Release candidate for `@mirolab/codex-discussion-mcp@0.1.3`. Publication and
public artifact verification have not yet been completed.

## Changes

- Automatically check public npm latest version metadata with a 1500 ms network
  deadline, in-process request coalescing, and a persistent 24-hour user cache.
- Add package update status and available-update notices to `models_list` in
  structured and legacy-readable text results while preserving model metadata
  and `accessVerified: false` ([PR #10](https://github.com/smallmiro/codex-discussion-mcp/pull/10),
  completing [issue #9](https://github.com/smallmiro/codex-discussion-mcp/issues/9)).
- Support `--no-update-check` and `CODEX_DISCUSSION_UPDATE_CHECK=0`. Registry and
  cache failures do not prevent discussions; no automatic installation,
  configuration rewrite, inference or restart occurs.
- Teach the portable skill to relay an available-update notice in the user's
  language once per newer version per session. Document installation-specific
  upgrades, reconnecting, and separately refreshing copied skill installations.
- Update version-pinned README installation examples to `0.1.3`.

## Update

For a **global npm installation**:

```bash
npm install -g @mirolab/codex-discussion-mcp@0.1.3
```

For a project-local installation, update the dependency in its project. For a
version-pinned `npx` configuration, update its configured package version to
`0.1.3`. Reconnect the MCP server after updating so the running process loads the
new code. Refresh copied skills separately, preserving local customizations;
updating npm does not overwrite those copies.

Existing `0.1.2` processes do not contain the version checker and must be updated
manually once before they can report future updates.
